# **App Name**: Voca Separator

## Core Features:

- File Upload: Intuitive drag-and-drop interface for file uploading.
- Automatic Split: AI-powered automatic audio splitting into vocal and instrumental tracks.
- Pitch Shifter: Pitch shifter to adjust the key of the vocal or instrumental track.
- Tempo Adjustment: Tempo adjustment tool to speed up or slow down the tracks.
- MP3 Compression: Basic MP3 compression options (different bitrates).
- Ad Integration: Display advertisements during loading screens and result displays.
- Watermarking: Watermark addition in free accounts.

## Style Guidelines:

- Primary color: Vibrant purple (#A050A0) for a modern and creative feel.
- Background color: Dark gray (#2A2A2A) to make the vibrant colors pop.
- Accent color: Electric blue (#7DF9FF) for interactive elements and call-to-action buttons.
- Headline font: 'Poppins' (sans-serif) for a modern and fashionable look.
- Body font: 'Inter' (sans-serif) to ensure readability and a neutral aesthetic.
- Use clear and concise icons that represent audio functions, in the style of a professional audio mixing suite. Favor filled icons for clarity.
- Subtle animations for loading screens and transitions to keep the user engaged.
